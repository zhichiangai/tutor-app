## V5.6.0 需完成

1. 保留現有已確認付款、預收與費用快照，**不直接 UPDATE/DELETE 原始已確認紀錄**。
2. 明確區分更正、沖銷與退款，逐筆不可變帳務分錄；每筆有原付款/預收/課程 reference、原額、更正額、原因、操作者、時間、同 Team/同學生約束。
3. 退款必須區分「核准退款」及「已經人工核實實際退款」，不可單靠按鈕宣稱金流退款成功；重複 reference / idempotency 不得雙扣，退款與抵扣並發也不能負餘額。
4. 家長能查看與自己孩子相關的付款/更正歷史，但不能看到其他學生、老師時薪、Team 管理費用；**學生不顯示任何金額**。
5. 通知只在外部寄信副作用經過分階段驗證後啟用；未驗證之前不寄信，也不把寄送成功當成收款成功。
6. 資料庫整合測試（Postgres、RLS、同 JWT 權限變更）、E2E 與管理者 GUI 逐項 PASS 才能標記 V5.6.0 開發完成。
