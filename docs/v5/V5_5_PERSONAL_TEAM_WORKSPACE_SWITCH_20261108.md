# V5.5｜設定中的個人家教／Team 工作空間切換（2026-11-08）

> 狀態：Draft PR #57（疊在 V5.4 PR #56），不是 Production 上線證明。

## 使用者決策

- 同一套「好好上課」網站，不做 V4／V5 兩套平行部署。
- V4 原本的個人家教功能完整保留；Team 專案與跨老師功能是追加，不取代既有個人課程。
- 老師從「設定 → 使用模式」切換 **個人家教**（預設）／**Team 團隊**。
- 目前資料是可重建的測試資料；不要求保存舊測試資料或回放正式 43 筆歷史 Migration 才能繼續 V5 功能開發。這不代表已授權立即清空正式 DB；正式建置仍須審核 Schema、RLS/Auth 和變更範圍。

## 模式與角色界線

| 模式／角色 | 功能入口 | 存取邊界 |
| --- | --- | --- |
| 老師 · 個人家教 | 今天、課程月曆、收付款、學生與家長、設定 | 延續 V4 原工作空間與 Supabase 權限 |
| 老師 · Team | 團隊與專案、Team 學生與課表、Team 帳務、設定與切換 | 既有 V5.2–V5.4 專用模組；每次依有效 roster/assignment/RLS/RPC 授權 |
| 家長／學生 | 原有家長、學生導覽 | 不顯示教師工作空間切換或 Team 財務；學生不可讀取金額 |

Team 不是老師／家長／學生角色的替代；UI 按鈕不授予 Team 權限。沒有 Team 指派的老師可看到工作空間說明，但不能存取 Team 學生與費用。

## 實作

- 仍使用 v2/index.html 和 v2/app.js；不刪除 V4 課程／學生／帳務程式。
- 工作空間模式儲存在目前 Google user ID 專屬 localStorage，避免跨帳號帶入。
- Team 的桌面／手機導航和個人導航分離；只載入目前 Team 分頁所需資料。
- 模式或 Team 分頁切換時，清理 Team 帳務、課表、邀請 UI 暫存；登出延續原隱私流程。
- 此 PR 不修改 SQL/Auth/RLS。Team entitlement 錨點及訂閱名額仍需另外審查。

## 驗收

- Node：登入教師限定、不同帳號偏好隔離、V4 舊導覽和家長學生角色不回歸。
- Playwright：只在合成隔離 GoTrue／PostgREST 上登入三角色、切換 Team、重整、切回 V4 月曆帳務。
- 行動尺寸：320／375／390／430 px。
- 正式網站仍需另行核准發布及 Codex GUI 實測；CI 成功不等於正式站 PASS。
